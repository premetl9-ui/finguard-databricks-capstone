# FinGuard Documentation

This folder contains the maintained project documentation for the FinGuard Databricks capstone.

## Files

- `FinGuard_Capstone_Project_Document.pdf` — formal capstone proposal (PDF is the maintained submission format).
- `FinGuard_Architecture_Diagram.png` — project architecture diagram.
- `architecture.md` — architecture summary.
- `implementation_details.md` — implementation clarifications requested during proposal review.
- `project_setup.md` — repository and development setup notes.

The Word version of the proposal is not maintained in GitHub; the repository keeps the PDF version instead.
